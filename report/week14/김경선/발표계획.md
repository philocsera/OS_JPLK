## 슬라이드 1 — 이름 기반 즉시 분류 / 우선순위·quantum 자동 조정 [01·02·03]

**PPT 구성:**
- 상단 텍스트: `이름 기반 즉시 분류 / 우선순위·quantum 자동 조정 [01·02·03]`
- 스크린샷: `--workload spin,cc --duration 120` 실행 결과
- 밑줄 표시:
  - `pid=3 name=sh NORMAL -> INTERACTIVE`
  - `pid=7 name=cc BATCH -> CPU_BOUND`
  - `setcls pid=3 cls=0 prio=4` / `setcls pid=7 cls=3 prio=12`

**발표 멘트:**

> "프로세스 이름을 보고 LLM이 sh는 INTERACTIVE, cc는 CPU_BOUND로 즉시 분류하고, priority와 quantum을 자동 조정합니다."

## 슬라이드 3 — 그룹 묶기 / fork bomb 탐지 및 차단 [05·06]

**PPT 구성:**
- 상단 텍스트: `그룹 묶기 / fork bomb 탐지 및 차단 [05·06]`
- 스크린샷: `--workload ftree --duration 60` 실행 결과
- 밑줄 표시:
  - `group 5: 13 proc(s) ['ftree']`
  - `PRE-EMPT fork-bomb: setjprio 5 19`

**발표 멘트:**

> "연관 프로세스들은 같은 group_id로 묶이고, LLM이 fork bomb으로 판단하면 그룹 전체 우선순위를 강등합니다."
