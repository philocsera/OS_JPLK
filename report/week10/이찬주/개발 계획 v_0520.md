# 10주차 개발 계획

- 금주 개발은 각 syscall 구현 및 llm에 필요한 struct proc을 잘 전달 가능한지까지의 기능을 구현하는데 목적을 둔다

## 1. 구현 기능

- `getmemstat` syscall 구현 (o)
- `setmemquota` syscall 구현 (o)
- `proc` 구조체에 `mem_quota` 추가 (o)
- `growproc`에서 quota 초과 검사 (o) 
- `memstat_test` 작성 (o) 
- `memstress` 작성 (o) 

## 2. 실험 결과

- quota 적용 전 `memstress` 실행 로그
- quota 적용 후 `memstress` 실행 로그
- `memstat_test`를 통한 `sz`, `quota` 확인 결과

## 3. 기준

- 프로세스별 메모리 사용량을 확인할 수 있는가.
- 특정 프로세스에 메모리 제한값을 설정가능한가.
- quota를 초과하면 `sbrk()`가 실패하는가.
