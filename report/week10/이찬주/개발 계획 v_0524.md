# xv6 Memory Quota 개발 진행 정리

## 이전까지 완료된 부분

- `getmemstat` syscall 구현
  - 프로세스별 `pid`, `state`, `sz`, `quota`, `name` 확인 가능
- `setmemquota` syscall 구현
  - 특정 pid의 `mem_quota` 설정 가능
- `proc.h`에 `mem_quota` 필드 추가
- `growproc()`에서 quota 초과 시 메모리 증가 차단
- `memstat_test`로 quota 값 변경 확인
- `memstress`로 quota 초과 시 `sbrk failed` 확인

## 새로 추가할 부분

- `memwatch.c`
  - 프로세스별 메모리 상태를 반복 관찰
  - quota 사용률 percent 출력
- `growproc` quota denied log
  - quota 때문에 차단된 순간 kernel log 출력
- `setmemquota` 안전 검사
  - 현재 `sz`보다 작은 quota 설정 방지
- `memwatch JSON 출력 모드`
  - bridge.py와 LLM agent가 읽기 쉬운 구조화 출력 제공
- `setquota.c`
  - xv6 shell에서 직접 `setmemquota(pid, quota)` 실행 가능
- 이후 `bridge.py`
  - memwatch JSON을 읽고 LLM 호출 여부 판단
